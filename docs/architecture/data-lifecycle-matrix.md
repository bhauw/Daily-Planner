# Daily Planner Field-Level Data Lifecycle Matrix

This matrix is a binding production requirement derived from the approved brief. It is not a claim that the M0.5 probes implemented production persistence. Classification happens before any durable write, cache insertion, diagnostic capture, temporary file, or AssistantJob creation. Uncertain content is Private.

`Ordinary` means non-Private content allowed by user settings. `Private` includes banking/sensitive financial content and any source whose classification is uncertain.

## Cross-cutting invariants

- A derived field inherits the highest privacy classification of any source or context that contributed to it.
- Every encrypted-persistence allowance in this matrix applies only to content classified `Ordinary`, unless a row explicitly names non-content metadata. Private or uncertain content-bearing values remain memory-only and never enter SwiftData content fields, durable jobs/caches, temp remnants, logs, crash diagnostics, notifications, the vault, style learning, or Codex. The sole durable Private source record allowed by the approved brief is an opaque source ID plus its classification.
- Privacy reclassification to a stricter class immediately purges now-ineligible durable derivatives and queued jobs.
- Encryption is not permission: only classification-eligible content may be encrypted and persisted.
- A schema/version mismatch, failed decryption, lost key, or failed rotation never falls back to plaintext. Purge and rebuild.
- Codex disclosure is per item and names categories/counts, not sensitive note titles or full paths.
- Scheduled scans can queue only encrypted/redacted eligible jobs. They never queue Private content or silently substitute another model.
